# Лабораторная работа №4 — Стили и темы

Студент: Карасюк Евгений Алексеевич, группа БОМ41ПРИ.

Android-приложение на Kotlin с XML-разметкой по заданию на страницах 44–47 методички.

## Запуск

Откройте папку `lr4` в Android Studio, дождитесь синхронизации Gradle, выберите эмулятор или подключённый телефон и нажмите Run. Требуется Android 7.0 (API 24) или выше. Проект использует SDK 37 и JDK 25.

Сборка из терминала в папке `lr4`:

```sh
./gradlew :app:assembleDebug :app:lintDebug
```

APK после сборки: `app/build/outputs/apk/debug/app-debug.apk`.

## Что показать при защите

1. При запуске открывается диалоговое окно без ActionBar. Общая тема `AppTheme` задаёт полупрозрачный янтарный фон `#5fffb000` и верхний регистр. У всех четырёх TextView явно указан `style="@style/style1"`: чёрный моноширинный текст 30 sp; размер из стиля имеет приоритет над 32 sp из темы. Среди полей есть ФИО и группа.
2. Итоговый экран содержит только текстовые поля, без кнопки перехода, как в примере методички.
3. В `styles.xml` определены общий стиль `style1` (30 sp) и наследник `style1.bigfont` (50 sp). На главном экране используется `style1`.

## Основные файлы

- `app/src/main/res/values/styles.xml` — собственный стиль и наследник.
- `app/src/main/res/values/themes.xml` — тема приложения и нейтральная тема демонстрации стилей.
- `app/src/main/res/layout/activity_main.xml` — итоговый экран с общим стилем `style1` у четырёх TextView.
- `app/src/main/java/com/example/lr4/MainActivity.kt` — наследуется от `Activity`, как в методичке.
- `app/src/main/AndroidManifest.xml` — применение темы ко всему приложению.

## Краткие пояснения

Тема задаёт общие значения для экрана, стиль применяется к отдельному элементу. Явно заданный XML-атрибут элемента имеет приоритет над тем же атрибутом в стиле. Наследование позволяет изменить только нужные свойства, сохранив остальные.

## Проверка

После повторной проверки сборка APK и Android Lint завершились без ошибок. Приложение установлено и проверено на эмуляторе Android 11 (API 30, ARM64): проверены тема и демонстрация стилей, ФИО и группа не обрезаются. В итоговой версии кнопка перехода удалена по образцу из методички. Высота поля группы изменена с фиксированных 40 dp на `wrap_content`.


## Установленный эмулятор

В Android Studio откройте **Tools → Device Manager** и запустите **Kotlin Labs — Android 11** (имя AVD: `Kotlin_Labs`). Затем выберите его в списке устройств и нажмите Run.

Запуск из терминала:

```sh
"$HOME/Library/Android/sdk/emulator/emulator" -avd Kotlin_Labs
```

Снимки в `screenshots` относятся к предыдущим проверенным версиям интерфейса.
